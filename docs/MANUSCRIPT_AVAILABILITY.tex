\paragraph{Data and Code Availability.}
The main analysis code, aggregate results, reproduction instructions, and
256-bit Secure Hash Algorithm (SHA-256) input hashes are publicly available at
\url{https://github.com/carminelau/asita2026-air-quality-reconstruction}.
Original provider observations and authenticated responses are available
from the corresponding author on reasonable request, subject to the
respective provider terms. Reproduction coverage and limitations are
documented in the repository. An archival digital object identifier (DOI)
will be added when the package is deposited.
