# Code and research-data policy

The MIT license covers the Python source, tests, and repository tooling
provided by the authors. It does not grant rights to provider observations,
authenticated API responses, grid geometries, or third-party material.

Public `results/` files contain aggregated study results and protocols.
Public `figures/` files contain the author-prepared publication graphics.
These files are supplied for transparent verification and citation of this
research; no additional blanket data license is asserted. The provider terms
continue to govern any underlying observations or derived content.

The repository intentionally excludes original observations, daily campus
records, device inventories, per-record model predictions, authenticated
payloads, and access credentials. The ignored `data/`, `reports/`, and
`generated/` directories are for local reproduction. Do not force-add them
without obtaining the relevant redistribution permissions.

Provider source URLs and input hashes support provenance and integrity; they
do not transfer ownership or access rights. Contact the corresponding author
for access arrangements. Live provider downloads can change independently of
this repository, and the original snapshots are necessary for exact input
verification.
